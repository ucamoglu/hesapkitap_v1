# Varlik360 App Icon

This folder contains the source-of-truth assets and export tooling for the
`Varlik360` app icon family.

Files:
- `export_varlik360_icons.swift`: Generates the master icon plus Android, iOS,
  and web exports.
- `master/`: Generated master assets used for store listings and future
  variants.
- `android/`: Generated adaptive icon layers.

Notes:
- The current exported icon keeps the yellow `+` accent to preserve the premium
  visual language requested for `Varlik360`.
- Future `Varlik360+` variants can be generated by extending the Swift exporter
  instead of redrawing assets platform-by-platform.
